# 灵感工具使用介绍

> 让"AI 辅助"从"帮你写"扩展到"帮你想"——卡文、构思、深化阶段的思考工具：故事种子、每日灵感卡片、角色采访、"如果…会怎样"推演器、灵感库，以及把任意文本炼成文风 Skill 的"一把炼化"。定位是**激发而非替代**。

---

## 一、入口结构

| 位置 | 功能 |
|---|---|
| 主页侧栏「灵感库」（独立页面） | 今日灵感卡片 + 故事种子生成器 + 灵感库列表 |
| 编辑器右栏「灵感」分组 | 角色采访、"如果…会怎样"推演器 |
| 主页侧栏「一把炼化」（独立页面） | 从文本 / 书籍提炼文风 Skill |

## 二、故事种子生成器

灵感库页面内嵌，题材 + 元素组合的构思起点：

- **输入**：题材（必填，如"武侠"）+ 元素组合（必填，逗号分隔，如"雨夜当铺、失忆的账房先生、一桩陈年旧案"）+ 语气（严肃 / 荒诞 / 温暖 / 黑暗，默认严肃）+ 数量（3 / 5 / 8 / 10，默认 5）+ 额外提示。
- **🎲 随机灵感**：AI 随机给一组"题材 + 三元素"并说明搭配理由，直接覆盖输入框；会主动避开时间循环、系统流等套路，并结合最近生成方向避重。
- **结果卡片**：标题、一句话钩子（logline）、扩展梗概、关键冲突点、结局方向；可「收藏」进灵感库，或「建书」——种子内容自动写入新书世界书（分类"故事种子"），AI 上下文立即可用。

## 三、每日灵感卡片

灵感库页面顶部"今日灵感"，一天一张、全部 AI 生成：

- **六种类型**：写作技法 / 场景范例 / 人物刻画角度 / 叙事手法 / 经典开头 / 写作格言；正文 150–400 字 Markdown。题材一半概率取自你最近在写的书。
- **操作**：收藏（入灵感库）、**换一张**（替换今日卡）、**换个题材**（忽略书籍类型随机抽题材）、**不再推荐此类**（屏蔽该类型，可随时点击解除）。
- 未配置模型时展示一张内置默认卡《先写下来》兜底。

## 四、角色采访

编辑器右栏「灵感 → 角色采访」：AI 扮演书中角色回答你的提问，帮你从角色内部理解人物。

1. 选角色 → 选采访角度（**童年 / 动机 / 秘密 / 关系 / 对某事件看法 / 自由** 六种，可中途切换）→「开始采访」。
2. 多轮流式问答，角色基于角色卡与近章摘要第一人称回答，不 OOC；可随时中止。
3. 「结束采访」→ AI 生成分条摘要预览 → 确认「添加到角色卡」才写入（含日期与角度）；完整对话存档可回看，历史采访可删除（已写入角色卡的摘要不受影响）。

## 五、"如果…会怎样"推演器

编辑器右栏「灵感 → 如果…会怎样」：剧情假设推演。

- **输入**：假设（如"如果主角在第三章就死了"）+ **锚点章节**（假设发生在该章之后，默认最新一章）+ 推演范围（3 / 5 / 10 章，默认 5）。
- 生成约需一分钟，报告包含：影响范围概述、**角色弧光对比**（原弧光 → 推演后）、剧情分支点（3–6 个，按章标注）、潜在风险（弧光断裂 / 伏笔失效 / 节奏崩坏 / 设定矛盾）、AI 建议（值得尝试 / 风险过高 / 需要调整）。
- 可「存入灵感库」；推演历史列表可回看。

## 六、灵感库

主页侧栏「灵感库」页面下方的跨书统一仓库，收录四类条目：**故事种子 / 灵感卡片 / 推演报告 / 采访摘要**。

- 类型筛选、"只看收藏"开关、关键词搜索；收藏优先 + 时间倒序。
- 条目显示类型徽标与所属书籍；种子条目可再次「建书」。
- 存储：种子与收藏的卡片为**全局共享**；推演报告与采访摘要**按书绑定**（随书备份、随书删除）。

## 七、一把炼化（SkillForge）

主页侧栏「一把炼化」：粘贴文本 / 上传文件 / 选库内书籍，AI 自动提炼为成体系文风 Skill。产出的 Skill 与手动创建完全同构，之后在编辑器右栏「Skill」面板按书启用即可生效（见 [指令体系说明](./指令体系说明.md)）。

- **素材三选一**：粘贴文本（上限 10 万字）、上传 TXT / Markdown（上限 5MB）、从书架选书（按章节均匀抽取，覆盖全书风格演变）。
- **智能采样**（默认开）：长文本按"头 20% / 中 50% / 尾 30%"比例抽取代表段落，大幅省 token；关闭则分片逐段分析，覆盖更全但调用更多。
- **成本确认**：先弹一次隐私确认（素材将发送给所配置的模型服务商），然后展示预估输入 / 输出 token、调用次数与所用模型，确认后才执行；执行中可取消。
- **预览与保存**：AI 产出后可编辑名称、描述、适用模式、优先级与文风指令正文（建议控制在 1500 字内，避免挤占 Skill 注入预算）；同名 Skill 可选覆盖或改名。原始素材不留档。

## 八、模型分工

灵感五件套同属「灵感与素材」域，均为中档模型建议：故事种子 / 灵感卡片 / 角色采访 / 假设推演 / 命名生成 / **一把炼化**。完整配置见 [模型接入说明](./模型接入说明.md)。

## 九、限制与提示

- 生成约需数十秒到一分钟（推演最久），界面会显示阶段进度，请耐心等待。
- 采访摘要不回注后续采访，保证每次视角新鲜；采访记录不会未经确认自动写入角色卡。
- 推演基于摘要链 + 角色卡 + 世界书组装上下文，锚点章之前的设定才会被纳入。
