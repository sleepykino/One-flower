# 编辑器基础使用介绍

> 编辑器是本应用的主写作界面：左侧章节树、中间富文本正文、右侧功能面板。本文覆盖与 AI 无关的写作基础——章节管理、正文排版、引用节点、章节大纲与节拍、版本历史、沉浸模式、随手记、导入导出。AI 四模式见 [AI辅助写作说明](./AI辅助写作说明.md)。

---

## 一、界面布局

进入一本书后，编辑器自上而下分为：

| 区域 | 内容 |
|---|---|
| 顶栏 | 「← 书架」、书名（悬停可重命名）、当前章节实时字数、工具组（随手记 / 大纲 / 专注 / 世界构建 / 面板折叠 / 全局查找 / 导出）、主题切换按钮 |
| 左侧栏 | 章节树 |
| 中间 | 正文编辑器（TipTap 富文本） |
| 右侧栏 | 功能面板，按「AI / 设定 / 灵感 / 资产 / 工具」五组竖排图标切换 |
| 底部状态栏 | 保存状态（已保存 / 保存中… / 未保存）+ 任务中心入口（有运行中任务时显示） |

- **保存**：停顿 3 秒自动保存；`Ctrl+S` 立即保存；切换章节时强制保存。保存同时会自动生成版本快照、调度后台章节摘要与 RAG 向量化。
- **主题**：顶栏主题按钮循环 浅色 → 深色 → 护眼，与设置页「外观」实时同步。

## 二、章节树

- **新建**：底部输入框输入标题，按 Enter 或点「+」；点某行的「+」可改为在该章节下新建子章节（多级嵌套）。
- **操作**：悬停章节行浮现四个按钮——大纲（编辑本章大纲与状态）、✎ 重命名、+ 添加子章节、× 删除（含确认）。
- **排序**：直接拖拽。拖到目标上半部 = 插到其前；拖到下半部 = 成为它的子章节。
- **状态徽标**：草稿（灰）/ 修订（琥珀）/ 定稿（绿），在大纲编辑卡中切换。
- **伏笔标记**：行尾绿点 `●N` = 该章埋设 N 处伏笔、蓝点 `●N` = 回收 N 处（在伏笔面板中管理，树上只作展示）。
- **卷**：数据上为多级章节，卷节点一般由导入 TXT/Markdown 时自动生成，界面无"新建卷"入口。

## 三、正文排版

- **块类型**：H1 / H2 / H3 标题、加粗、斜体、引用（❝）、**对白块**（左侧绿色强调条，块内按 Enter 自动回退普通段落）、分隔线。
- **外观**：工具栏右侧三个下拉——字体（宋体 / 楷体 / 黑体等 9 种）、字号（14–24，默认 16）、行距（1.4–2.5，默认宽松 1.9）。与设置页「外观 → 编辑器」双向同步。
- **粘贴**：默认保留外部富文本格式；设置页「外观 → 粘贴清洗（转为纯文本）」开启后剥离格式、按行拆段。粘贴 / 拖入本地图片会自动存入本书图库并插入正文。
- **全局查找**：顶栏「全局查找 `Ctrl+Shift+F`」，跨章节全文查找替换，支持正则与大小写开关；批量替换前会确认影响范围。

## 四、引用节点（@角色 / [[世界书]] / ##章节）

正文中直接引用设定，AI 生成时**全文注入**（不受 RAG 检索相似度影响）：

| 节点 | 触发方式 | 渲染 |
|---|---|---|
| `@角色` | 按 `@` 键，或工具栏「@引用」 | 紫色胶囊 |
| `[[世界书条目]]` | 800ms 内连按两次 `[`，或工具栏「[[条目]]」 | 天蓝胶囊 |
| `##章节` | 800ms 内连按两次 `#` | 绿色胶囊 |

弹窗内可输入过滤，Enter 选中第一项，Esc 关闭。世界书仅列出**已启用**条目。三类引用有独立的 token 预算（约 1500），可通过右栏「上下文」面板查看实际注入。

## 五、章节大纲、摘要与节拍

- **本章大纲**：章节树悬停点「大纲」展开编辑卡——填本章梗概（写作前定梗概，写作后对账）、切换章节状态、生成 / 重生成 AI 摘要。摘要保存章节后也会在后台自动生成，用于前情上下文。
- **批量摘要**：章节树右上「批量摘要」，为缺摘要或内容已变更的章节批量补摘要（任务中心托管）。
- **全书大纲**：顶栏「大纲」打开 `outline.md`（编辑 / 分屏 / 预览三视图，默认分屏）。作为前瞻约束注入续写 / 改写 / 对白 / 检查 / 长文节拍规划；HTML 注释行不注入；可随时关闭注入开关。详见 [指令体系说明](./指令体系说明.md)。
- **章节节拍**：编辑器内左侧竖排「节 / 拍 / ▶」按钮展开节拍栏。节拍 = 本章内的场景 / 事件小目标：描述 + 目标字数（默认 300），可勾选完成、拖拽排序。存在未完成节拍时，AI 面板会出现「按节拍定向」开关（默认开）。整章按节拍批量生成请用 [长文模式说明](./长文模式说明.md)。

## 六、版本历史

右栏「工具 → 版本」：

- **快照**：每次保存（3 秒防抖 / Ctrl+S / 切章）自动落一版，首版存全文、其后存增量差异，无手动创建入口。
- **预览 / 对比 / 回退**：每版三个操作。对比需先点一个版本作基准，再点另一版「对比到此」，展示段落级增删；「回退」会用该版本覆盖当前正文（当前正文先存为历史版本，可再回退）。
- **清理**：头部「清理旧版本」保留最近 50 版 + 每天 1 版。

## 七、沉浸专注模式

顶栏「专注」进入全屏写作：隐藏工具栏与面板，右上角浮动条可切 主题（标准 / 护眼 / 夜间，独立于全局不回写）、开关**打字机滚动**（光标所在块自动居中）、查看本次字数与时长。`Esc` 或「×」退出。

## 八、随手记（备忘录）

顶栏「随手记」打开全局跨书速记浮窗：

- 左侧备忘录列表（置顶优先），右侧「编辑 / 预览」双视图，Markdown 渲染，裸链接自动转为可点击。
- 图片附件：按钮添加 / 直接粘贴剪贴板图片 / 拖入文件。
- `Ctrl+S` 保存；删除需确认（图片附件一并删除）。
- 备份：随**自动定期备份**单独成包；设置页「备份与恢复」可导入备忘录备份（按新 ID 重建为副本）。见 [书架与数据安全说明](./书架与数据安全说明.md)。

## 九、导入与导出

- **导入**：书架页「导入」下拉两项——「导入文档」（TXT / Markdown，按章节标题自动切分卷 / 章，支持直接拖文件到书架）与「导入备份」（.zip 恢复整本书）。切分识别「第X卷 / 第X章 / 第X节 / 第X回 / Chapter N」及序章、楔子、尾声等固定章名；无边界时导入为单章。
- **导出**：编辑器顶栏「导出」，范围选全书 / 单章，格式：Markdown / 纯文本 TXT / EPUB 电子书 / Word 文档 / 备份包 zip。EPUB、DOCX、Markdown 默认内嵌封面与正文插图（TXT 忽略图片）；备份包包含设定、指令、地图底图等全部数据，可在书架重新导入。

## 十、限制与提示

- 顶栏没有"保存"按钮，保存靠自动保存 + `Ctrl+S`，状态看底部状态栏。
- 快捷键仅「保存当前章节」与「全局查找」可自定义（设置 → 快捷键）。
- 正文中的图片节点支持点击编辑图注、调宽度与对齐；文件缺失时显示占位不报错。
- 沉浸模式内切换的主题不会写回全局主题。
