# 长文模式使用介绍

> 长文模式（P2.1-M7）是**章节级**的"规划 → 生成 → 自洽"四步循环：用 AI 先规划一章的节拍表，再逐拍生成正文，最后对接缝做自检。它是编排层，循环调用既有"续写"能力，因此本书的 **agents.md 指令、全局提示词、文风 Skill、三路 RAG、模型分工** 都会自动生效，无需额外配置。

---

## 一、进入方式

在编辑器右侧栏打开 **「AI」** 分组，点击 **「长文」** 标签；或在 AI 面板顶部模式栏点击 **「长文」**；在"续写"模式下底部也有"需要整章生成？切换长文模式 →"入口。

> 若本书存在进行中的长文会话，编辑器顶部会弹出琥珀色提示条：「检测到未完成的长文生成（第 X/Y 拍，状态：进行中 / 已暂停 / 待审阅）」，可一键"恢复"或"丢弃"。
>
> 若上次是应用重启导致的异常中断，进入长文面板时会提示"已自动置为暂停"，直接恢复或丢弃即可（僵尸会话自愈，不会留下无法处理的死会话）。面板步骤条右侧还有「?」按钮，可随时播放功能引导。

**前置条件：**
- 已从章节树**选择目标章节**（长文针对当前章节生成）
- 已在"设置 → 模型接入"**添加并配置了模型**（未配置会在调用时报错）
- （可选）已启用文风 Skill / 编写本书 agents.md，质量会更稳

---

## 二、四步向导

### ① 节拍表（规划）

| 项 | 说明 |
|---|---|
| 拍数 | 3–8 拍，默认 5。每拍 = 一个场景 / 事件单元 |
| 总字数 | 3000–8000 字（步进 500），默认 4000 |
| 补充提示 | 可选：本章基调、必须出现的事件、禁止内容等；**会逐拍透传**到每次正文生成 |
| 参与角色 | 可勾选参与本章生成的角色卡；**不勾选则默认注入本书全部角色卡** |

点 **「AI 生成初稿」**，AI 会综合以下素材规划节拍表：
- 前情摘要（近 5 章摘要，由远及近）
- 本章大纲与**全书大纲前瞻**（避免与后续剧情冲突）
- 本章已有正文尾段
- 参与角色的角色卡概要
- 相关世界书 / 原文片段（三路 RAG 检索）
- 你填写的补充提示

初稿生成后可在列表中**直接编辑每个拍的文本和目标字数、拖拽排序、添加 / 删除节拍**（新拍默认字数 = 总字数 ÷ 拍数）。也可以点 **「从章节节拍导入」**，直接复用编辑器左侧节拍栏里已经写好的章节节拍（不依赖 AI 初稿，默认每拍 300 字）。

调整好后点 **「下一步：成本确认」**（至少保留一条非空节拍）。

### ② 成本确认

展示预计 **LLM 调用次数**（= 节拍初稿 × 1 + 拍数 + 接缝自检批数，接缝按每批 4 条分批）与 **预计消耗 token**（按各拍字数 × 2.2 + 单次上下文开销 + 初稿 / 自检估算）。确认无误点 **「确认并开始生成」**；想改节拍可「返回编辑节拍」。

### ③ 生成进度

- 任务由**任务中心托管**，面板内显示进度条与"N/M 拍"详情，并实时显示"已用约 X / 预估 Y token"
- 逐拍生成，内容**流式渲染到编辑器临时节点**，一拍拍落正文并自动保存
- 每拍即一个保存粒度，**恢复时不重做已完成拍**
- 支持 **暂停**（「暂停（当前拍中断，完成后拍已保留）」——已完成拍保留，中断的半拍文本停在编辑器临时节点，可用"保留 / 丢弃 / 继续补完"三选项处理）、**恢复**（「恢复生成（从第 N 拍）」，从下一拍继续）、**丢弃**（删除会话，已落正文保留）
- 生成期间可**切换到其他章节继续写作**：任务自动后台化，每拍直接落盘到目标章节，不丢内容

### ④ 接缝审阅（自洽）

全部拍完成后自动对接缝做**自检**：检查相邻两拍"前一拍结尾 → 后一拍开头"的衔接问题，按 **语气 / 称呼 / 时间线 / 重复 / 其他** 五类展示，并标注所在接缝（第 N 拍 → 第 N+1 拍）。点击任一问题可**滚动编辑器定位**到接缝位置；无问题则提示"接缝自检未发现问题"。

审阅完毕后点 **「结束并清理会话」**。

> 接缝自检结果会随会话**持久化**：即使生成完成后关闭应用，下次仍可通过琥珀色提示条"恢复"，回看遗留的接缝审阅。

## 三、会话与恢复

- 每本书**同时最多一个**进行中的长文会话（状态 `ready / running / paused / seam-review`）
- 会话落盘到 `longform_sessions` 表（含节拍表、当前拍、已用 token、补充提示、参与角色、接缝自检结果等）
- **关闭应用、退出编辑器、切换章节**都不会丢：回到编辑器后用"长文"标签或琥珀色提示条可恢复
- 异常中断的会话（应用重启 / 进程退出）会自动置为 `paused` 并提示恢复或丢弃；"丢弃"则删除会话记录（**已写入正文的内容会保留**，只丢规划与进度）

## 四、模型分工（成本控制）

长文涉及的三个功能点都可在 **设置 → 模型分工** 中单独绑定不同强度的模型：

| 功能点 | 设置页名称 | 用途 | 建议强度 |
|---|---|---|---|
| `continue` | 续写 | 正文生成（每拍），长文正文同此配置 | 强模型（写作生成） |
| `longform-draft` | 长文节拍规划 | 节拍表初稿 | 强模型 |
| `longform-seam` | 接缝审阅 | 接缝自检 | 中档模型（规划与校验） |

> 用量统计页中对应显示为「长文·节拍规划」「长文·接缝自检」。

未绑定时统一回退到默认配置（第一组）。

---

## 五、限制与提示

- 长文目标是**单章**生成，规模上限为 8000 字；跨章的连续创作请分章多次使用
- 拍数与字数仅为规划参考，实际输出可能略有偏差；单拍目标字数限制在 100–3000
- 长文为角色卡分配更大的上下文预算（5000 字），多角色同场生成更稳
- 补充提示既影响节拍规划，也会在每一拍生成时再次注入
- 接缝自检为 AI 辅助，不保证完全发现所有问题
