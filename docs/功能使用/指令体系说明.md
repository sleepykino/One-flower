# 指令体系使用介绍

> 本应用用四件工具精细把控 AI 行为：**agents.md（本书总纲）> 全局提示词 > Skill 文风包** 三层指令按优先级注入每次生成，**hook.md** 则在生成完成后做输出校验。前两者解决"怎么写"，hook 解决"写完检查"。

---

## 一、进入方式

- **本书指令（agents.md + hook.md）**：编辑器右栏「AI 助手」面板 → 模式栏下方「本书指令」按钮。入口旁有两个状态徽标：绿点「已注入」（agents.md 生效中）、琥珀点「校验N条」（hook 规则数）。
- **全局提示词**：设置页 →「指令与风格 → 全局提示词」。
- **Skill 文风包**：编辑器右栏「AI」分组 →「Skill」tab。
- **全书大纲**（也随生成注入的前瞻约束）：编辑器顶栏「大纲」，见 [编辑器基础说明](./编辑器基础说明.md)。

## 二、agents.md（本书创作总纲）

每本书独立一份，**以最高优先级注入本书所有 AI 生成**（续写 / 改写 / 对白 / 检查 / 长文 / 剧本），适合写世界观铁律、称谓规范、写作禁令。

- 编辑弹窗为「编辑 / 分屏 / 预览」三视图（默认分屏），Markdown 实时预览，Ctrl+S 保存。
- 「插入示例」会填入注释化模板（世界观铁律 / 称谓规范 / 写作禁令三节）——**示例条目均为 HTML 注释，不删除注释就不会生效**，可放心参考后改写。
- 文件随书保存于本书项目目录，随书备份导出 / 导入。
- 注入预算约 1500 token，超出截断；未创建或内容全为注释时不注入。

## 三、全局提示词

应用级、跨所有书生效，注入所有 AI 模式 system 段，适合写个人写作习惯（如"避免使用'仿佛'"）。

- 每条一行的列表：回车或「添加」新增；可单独启停、上下排序；右上「总开关」一键全停。
- 预算 600 token，页脚显示已启用条目的 token 合计，超出截断。
- 冲突时优先级高于任何 Skill，低于本书 agents.md。

## 四、Skill 文风包

Skill = 一个目录内的 `SKILL.md`（YAML frontmatter + Markdown 正文），**纯声明式指令，只注入 Prompt，不执行代码**。适合成体系文风：武侠古典、本格推理、硬科幻……应用首次启动会内置若干示例 Skill（含"中文小说去AI味"），仓库 `skills/` 目录还有十余个题材样例可参考。

| 操作 | 说明 |
|---|---|
| 启用 / 停用 | 右栏「Skill」tab 勾选，**按书生效**（每本书独立勾选） |
| 适用模式 | frontmatter `applies_to` 控制注入 续写 / 改写 / 对白 / 检查 中哪些模式；**一致性检查不注入文风** |
| 优先级 | `priority` 1–99，数字大优先；多个 Skill 按优先级降序注入，整体预算约 2000 token |
| 新建 | 面板「新建」打开向导：名称（目录名）、描述、适用模式、优先级、文风指令正文（建议按"用词偏好 / 句式 / 禁忌"结构写，越具体越有效） |
| 导入 / 导出 | 面板「导入」（.zip / .skillpack，同名可选覆盖或改名）与每行「导出」，方便分享 |
| 热重载 | Skill 目录（`~/.novelagent/skills`）文件监听，改动即时生效；异常时点「重新扫描」 |

批量从已有文本提炼 Skill 请用「一把炼化」，见 [灵感工具说明](./灵感工具说明.md)。

## 五、优先级与注入顺序

每次 AI 生成的 system 段按此顺序组装（冲突时以高优先级为准）：

```
模式任务指令 → 篇幅要求 → agents.md（最高） → 全局提示词 → 节拍约束 → Skill 文风包
```

各层有独立 token 预算（agents.md 1500 / 全局提示词 600 / Skill 2000）。每次实际注入了什么、占多少 token，可在右栏「设定 → 上下文」面板逐段查看。

## 六、hook.md（输出规则）

**不是指令层，是生成完成后的自动校验**。每行一条规则，语法：

```text
replace /正则/flags => 替换文本
warn /正则/flags => 提醒内容
block /正则/flags => 原因（命中则丢弃本次输出并自动重试一次）
```

- 非正则直接写关键词即按字面匹配；`#` 开头为注释。
- **可视化编辑**：「本书指令」弹窗内规则编辑视图，动作下拉（替换 / 提醒 / 阻断）+ 匹配 + 值，非法正则会行内提示"该规则将被跳过"；也可切「源码」直接改文件。
- **测试沙盒**：粘贴一段文本点「运行测试」，用与生产完全相同的逻辑试跑规则，replace 结果可预览，无需真的生成。
- 命中结果在 AI 面板底部展示（已替换 / 提醒 / 已阻断 × 次数）；block 自动重试仅续写 / 改写生效且只重试一次。
- hook.md 随书保存与备份；读取失败按无规则处理，不打断生成。

## 七、限制与提示

- 指令不是"越强越好"：预算有限，写具体、写少量关键规则效果最好。
- agents.md 与 hook.md 都随**手动备份与自动备份**走；全局提示词与 Skill 属应用级数据，换机需单独处理。
- Skill 目录为全局共享（跨书），启用状态按书记忆。
