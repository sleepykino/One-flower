# 模型接入与统计使用介绍

> 模型自由是本应用的核心卖点：云端（DeepSeek / 智谱 / Kimi / 通义 / OpenAI / Claude / Gemini / 硅基流动…）与本地（Ollama / LM Studio / ComfyUI）即配即用；「模型分工」为每类任务绑定不同强度的模型，成本质量两手抓；用量与写作统计帮助你掌握消耗与产出。

---

## 一、设置页结构

设置页左侧分区：「模型与服务」（模型接入 / 模型分工 / 用量统计）、「指令与风格」（全局提示词 / 指令说明）、「外观」（编辑器）、「数据」（备份与恢复 / 数据管理）、「通用」（快捷键 / 使用引导 / 更新与关于）。

## 二、模型接入

### 快捷预设（粘贴 Key 即用）

12 张预设卡片，点击弹窗内**粘贴 API Key**（附"获取 Key ↗"直达官网）→ 选模型 →「测试并保存」即可；预填地址与推荐模型，卡片信息可改。

| 类别 | 预设 |
|---|---|
| 云端对话 | DeepSeek / 智谱 GLM / 火山方舟·豆包 / Kimi / 通义千问·百炼 / OpenAI / Anthropic Claude / Google Gemini / 硅基流动（聚合平台） |
| 本地 | Ollama（`localhost:11434`）/ LM Studio（`localhost:1234`）/ ComfyUI（`127.0.0.1:8188`，生图专用） |

- **本地预设免 Key**：绿色提示"本地服务无需 API Key"；模型下拉旁「拉取模型列表」可从端点直接拉取（Ollama 需先 `ollama pull`）。
- **+ 自定义配置**：任意 OpenAI 兼容端点；协议四种——OpenAI 兼容 / Anthropic / Google / ComfyUI。
- **Key 安全**：API Key 存入系统钥匙串（Windows 凭据管理器），不落数据库；删除配置时同步删除密钥。

### 默认配置概念

- 「已添加配置」列表中可「设为默认」（紫色徽章）。
- **回退规则**：功能未在"模型分工"绑定 → 用默认配置 → 未设默认则用第一组配置。
- ComfyUI 配置只能绑定到「图片生成」；误绑到对话功能会被自动拦截并回退对话模型。

### 本地模型与离线 RAG

Ollama / LM Studio 免 Key 接入即可离线对话；把「向量嵌入」也绑到 OpenAI 兼容的本地端点（如 Ollama 的 embedding 模型），可实现完全离线的世界书 RAG。注意 **Anthropic 无 embeddings 接口**，向量嵌入请选 OpenAI 兼容或 Google 配置。

## 三、AI 模型分工

按**功能域**分组，为每类任务单独绑定配置（下拉选择，即时生效，右侧灰字显示"实际使用：某模型"）：

| 功能域 | 功能点 | 强度建议 |
|---|---|---|
| 写作生成 | 续写（长文正文同此配置）/ 改写 / 对白 / 长文节拍规划 / 剧本逐场生成 | 强 |
| 规划与校验 | 一致性检查 / 错字检查 / 接缝审阅 / 设定事实抽取 / 推导链 / 剧本大纲 | 中 |
| 灵感与素材 | 故事种子 / 灵感卡片 / 角色采访 / 假设推演 / 命名生成 / 一把炼化 | 中 |
| 视觉生成 | 图片生成（需生图配置）/ 图片提示词转写 / 地图生成 | 中 |
| 向量与后台 | 章节摘要（后台自动）/ 向量嵌入（后台自动） | 省 |

- 徽章含义：**强**（建议强模型）/ **中**（中档即可）/ **省**（省钱优先）；带"后台自动"标的是保存后静默运行的高频任务，建议绑便宜模型。
- 「全部用默认配置」一键清空所有绑定。
- **生成安全网**（高级项）：单次回复的 token 兜底上下限（默认 8192 / 512），目标字数 ×2.2 后夹在此区间；一般无需修改。

## 四、用量统计

设置 →「模型与服务 → 用量统计」：

- **汇总卡**：今日 / 近 7 天 / 累计 token 与累计调用次数。
- **近 14 天柱状图**（悬停看当日 token 与次数）；分布两栏：**按功能点**（20 项，如"长文·节拍规划""剧本·逐场"）与**按书 Top 8**。
- **口径说明**：覆盖对话类调用（流式无 usage 时按字符估算，中文 1 字 ≈ 1 token）；**不含向量嵌入与图片生成**；记账不影响生成。
- **明细保留期**：30 / 90 天（默认）/ 180 / 365 天 / 永久；过期明细自动清理并并入"累计"锚点，累计数字不缩水；可手动清理或清空全部明细。

## 五、写作统计

编辑器右栏「工具 → 统计」（每 15 秒自动刷新）：

- **今日卡**：今日字数、连续写作天数（streak）、今日时长；**日更目标**进度条（默认 3000 字，可改）与全书目标进度。
- **近 30 天趋势折线图**，标注峰值字数 / 天。
- 数据按书记录：保存带来的字数增长即时落库；目标按书保存。

## 六、快捷键 / 外观 / 更新

- **快捷键**：可自定义「保存当前章节」（Ctrl+S）与「全局查找」（Ctrl+Shift+F）两项；需含 Ctrl/Alt 或为 F 键（避免覆盖正文输入），有冲突检测，可一键恢复默认。
- **外观**：全局主题三选（浅色 / 深色 / 护眼，与顶栏按钮同步）；编辑器字体 / 字号 / 行距（与编辑器工具栏双向同步，带实时预览）；「粘贴清洗」开关。
- **更新检查**：启动静默检查 GitHub Release（默认开、24 小时一次、失败静默）；发现新版弹窗可"忽略此版本"，一键用系统浏览器打开下载页；设置页可手动「立即检查更新」。

## 七、限制与提示

- AI 功能需要**至少一组 Provider 配置**，未配置时相关功能会报错并给出指引。
- 图片生成仅支持 OpenAI 兼容平台与 ComfyUI；向量嵌入不支持 Anthropic。
- 「按书」统计只记录调用发生时所在的书，模型本身不按书绑定。
- 长文 / 剧本逐场生成等任务的详细成本估算见对应功能文档（[长文模式说明](./长文模式说明.md)、[剧本工作台说明](./剧本工作台说明.md)）。
