# 世界地图使用介绍

> 世界构建画布（Konva 渲染）：像画像素画一样涂刷多层地形，摆放 55 种内置图标元件与全局素材，连线道路、添加标注，还能用预设算法或 AI 一键生成。成品可导出 PNG 或直接插入正文当插图。

---

## 一、进入方式

编辑器顶栏「世界构建 → 地图」打开全屏「地图编辑」窗口。首次进入自动创建一张 1600×1000 的新地图。三栏布局：顶部工具栏（撤销 / 重做 / 缩放 / 预设生成 / AI 生成 / 导出 PNG / 插入正文 / 保存）、左侧栏（地图列表 / 工具 / 地形 / 元件库 / 素材库 / 图层）、右侧属性面板。窗口右上「?」可播放分步引导。

## 二、地形涂刷

- **图层**：支持多层瓦片图层（陆地层 / 植被层……），可新建、显隐、重命名、排序；「地形」区顶部「目标层」下拉决定笔刷作用层。空层时笔刷落下第一笔会自动创建"地形"层。
- **22 种内置地形瓦片**：水域（深海 / 浅海 / 河流 / 沼泽）、平原（草原 / 旷野 / 农田 / 沙滩 / 沙漠）、植被（森林 / 松林 / 丛林 / 秋林）、山地（丘陵 / 山脉 / 雪原 / 火山 / 冰川）、人造（道路 / 桥 / 街区 / 废墟）。
- **工具**（快捷键见括号）：笔刷（B，档位 1/2/3 对应覆盖半径）、橡皮（E）、填充（油漆桶，同地形连通区域整体替换）、吸管（取色并切回笔刷）；「仅覆盖已有」勾选后笔刷只落在已有地形上（陆地刷植被等覆盖场景）。另有选择、抓手、连线、区域、删除五个结构工具。
- **自定义纹理**：素材库底部「+ 纹理」上传小图（≤256px，png / jpg / webp / bmp）作为可刷的瓦片纹理。

## 三、元件、素材与节点

- **元件库**：55 个 emoji 图标（地形 / 水文 / 植被 / 聚居 / 建筑 / 军事 / 奇幻七类），选中后点击画布放置地点节点。
- **全局素材库**：跨书共享。内置 28 个简约矢量素材；可上传 PNG / JPG / SVG 等贴图（贴图支持连续放置，Esc 停止）；选中节点后右侧可调 HSV（色相 / 饱和 / 明度）、大小（0.3–3）、旋转、不透明度。删除自定义素材前会做**跨书引用检查**，强制删除后引用处显示占位框；内置素材不可删。
- **节点属性**：名称、图标 / 圆 / 方 / 多边形形状、颜色、描述、**关联世界书条目**（关联后标签带 📄 并显示条名副标题）。支持 Ctrl+C/V、Ctrl+D 就地复制、右键菜单（复制 / 置顶 / 置底 / 删除）。
- **连线（道路 / 航线）**：连线工具依次点两个节点；绘制中 **Shift+点击画布追加折线拐点**；选中后可拖拐点手柄、双击删拐点；右侧可设实线 / 虚线、折线 / 平滑、线宽 1–8、颜色、箭头。
- **标注**：字号 10–32、颜色、描边（可无）、**竖排文字**开关。
- 「自动布局」按钮对地点节点做力导向排布（可撤销）。

## 四、预设地形生成

工具栏「预设生成」：**环岛 / 群岛 / 大块陆地 / 大岛屿 / 小岛屿 / 泛大陆 / 半岛** 七种预设（纯本地算法，不消耗 AI）。

- 可调参数：陆地占比（0.1–0.6）、海岸粗糙度（0.3–1.2）、岛屿数量（仅群岛）、对称（左右 / 上下）、气候色系（温带 / 干旱 / 湿热）。
- **聚居点撒点**：0–20 个（默认 6，0 为关），自动落在宜居地块；沿海生成港口 / 渔村，内陆生成城市 / 城镇 / 村庄，作为地点节点追加。
- **seed 锁定**：勾选后同参数重新生成结果完全一致，可精确复现或分享参数。
- 「新建一层」默认勾选，生成结果放到新图层不覆盖现有地形；结果可撤销。

## 五、AI 能力

| 能力 | 说明 | 模型分工 |
|---|---|---|
| AI 生成地点布局与道路 | 根据书名与设定生成 8–18 个地点节点 + 道路 / 航线，成功后新建一张"AI 生成地图" | 「地图生成」（对话模型，中档） |
| AI 生成风格化底图 | 生成 1536×1024 俯视风格化底图铺在画布底层（可拖动 / 锁定） | 「图片生成」（生图模型） |

## 六、导出与产出

- **导出 PNG**：右侧「导出选项」可选**透明背景**与倍率 **1x / 2x / 3x**（默认 2x）；导出产物恒为浅色渲染，不随界面主题变化。
- **插入正文**：一键把当前地图以 2x PNG 插入正文光标处作为插图（需已打开章节），并自动入库图库。
- **保存**：Ctrl+S 或工具栏「保存」；切换地图 / 关闭窗口自动保存，标题栏显示"就绪 / 有未保存修改 / 已保存 HH:mm"。

## 七、数据与备份

- 地图结构（节点 / 连线 / 多层瓦片）存于本书数据库，底图文件存应用数据目录。
- **随书备份包含地图数据与底图**；但**全局素材库不属于单书备份**——换机恢复后，引用了自定义贴图的节点会显示占位框，需重新上传同名素材或删除节点。

## 八、限制与提示

- 快捷键：Ctrl+Z 撤销 / Ctrl+Y 重做 / Ctrl+S 保存 / B 笔刷 / E 橡皮 / Esc 停止；撤销栈上限 50 步。
- 画布尺寸可在右侧属性面板调整（宽 400–6000、高 300–4000），提供 1600×1000 / 2400×1400 / 3200×1800 快捷档。
- AI 生成前需先在「设置 → 模型接入」配置模型，详见 [模型接入说明](./模型接入说明.md)。
