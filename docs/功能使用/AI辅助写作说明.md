# AI辅助写作使用介绍

> 编辑器右侧「AI 助手」面板提供四种生成模式：**续写 / 改写 / 对白 / 检查**（另有一个独立的长文 tab，见 [长文模式说明](./长文模式说明.md)）。AI 会自动组装上下文——前情摘要链、近章原文、三路 RAG、角色卡、引用节点与三层指令——你只需要选模式、给要求。

---

## 一、进入方式与前置条件

- 编辑器右侧栏「AI」分组 →「AI 助手」，顶部模式栏切换 续写 / 改写 / 对白 / 检查。
- 前置：已在「设置 → 模型接入」配置模型；改写需先在正文选中一段文本；对白需填写场景描述并勾选参与角色。
- 模式栏下方常驻「本书指令」入口，右侧状态点显示 agents.md「已注入」与 hook「校验N条」。

## 二、续写

光标放在续写位置即可，无需选中文本。

| 项 | 说明 |
|---|---|
| 续写要求 | 可选，如"主角识破陷阱，引出幕后黑手"，以【要求】注入 |
| 节拍定向 | 本章存在未完成节拍时出现，默认开启，AI 严格围绕当前节拍写作 |
| 目标字数 | 默认 1000，可选 500 / 1000 / 2000 / 3000 或自定义（≥100）；写到自然段收束即止，宁短勿凑 |
| 温度 | 默认 0.8（0 严谨确定，2 发散大胆） |
| 候选数 | 1–3 条（默认 1）；多候选每条独立过 hook 校验，完成后点击切换预览，"保留此候选"或"全部丢弃" |
| 多轮会话 | 开关默认关。开启后生成进入"会话块"：可连续下达微调指令原地迭代（如"再压抑一点、节奏更快"），支持「与上一版对比」「采用进正文」「丢弃」，采用 / 丢弃后自动清账 |

- **流式输出**：内容实时渲染到编辑器临时节点，流式中可点红色「停止」。
- **中断三选项**：停止后出现「已生成 N 字，请选择」——**保留**（落正文）/ **丢弃** / **继续补完**（以半截内容为上文继续生成并合并）。
- **上下文自动组装**：最近章节取原文 + 更早章节取摘要链（约 4000 token、上限 20 章）；三路 RAG（摘要链 / 世界书条目 / 原文片段各取 top 若干）；你勾选的参与角色卡；正文中的 @ / [[ ]] / ## 引用全文；agents.md、全局提示词、文风 Skill、全书大纲。每次实际注入可在右栏「上下文」面板查看（含各段 token 占用）。

## 三、改写

先在编辑器**选中**要改写的文本，填写改写要求（选视角后可留空）。

- **叙述视角**：默认"不切换视角"；可选本书任一角色的视角（注入其角色卡保持一致性），或固定三视角：上帝视角 / 旁观者视角 / 未来回望视角。
- 生成后流式**替换**选中区域，同样出现保留 / 丢弃 / 继续补完三选项；支持目标字数、温度与多候选。

## 四、对白

填写场景描述（如"客栈中，主角与神秘剑客对峙"）+ 勾选参与角色（注入角色卡），点「生成对白」。结果流式写入光标处，确认保留后成为正文段落。此模式没有字数 / 温度 / 候选数设置，块命中 hook 阻断规则时不会自动重试。

## 五、检查

两个独立按钮：

- **一致性检查**：比对当前章正文与本书全部角色卡、全量启用的世界书条目，以及"时代感基线"（设定事实 + 推导链，来自世界书面板「设定事实」，可检测"无光学工艺却出现望远镜"式越级矛盾）。结果按严重度（高 / 中 / 低）列出矛盾、关联设定与原文片段。
- **错字检查**：只报告有把握的错别字，每条显示 红色删除线原文 → 建议写法 + 原因，可「定位」或一键「修正」。底部提示：AI 校对存在误报可能，修正前请确认上下文。

## 六、hook.md 输出校验

每次生成完成后自动执行本书 hook.md 规则（在「本书指令」中编辑，见 [指令体系说明](./指令体系说明.md)）。命中后在 AI 面板底部出现「hook 规则已应用」卡片：

| 动作 | 行为 |
|---|---|
| replace 替换 | 自动替换命中文本（支持 $1 反向引用） |
| warn 提醒 | 仅提示，不修改文本 |
| block 阻断 | 丢弃本次输出并**自动重试一次**（仅续写 / 改写；对白不重试）；二次仍命中则保留文本并展示命中原因 |

## 七、成本与模型分工

- 各模式可在「设置 → AI 模型分工」绑定不同模型：续写 / 改写 / 对白建议强模型，一致性检查 / 错字检查中档即可。见 [模型接入说明](./模型接入说明.md)。
- **生成安全网**（模型分工页高级项）：目标字数 × 2.2 换算为 maxTokens 并夹在"单次回复上限 / 下限"（默认 8192 / 512）之间；超长输出按段界 → 句界自动收束，一般无需修改。

## 八、限制与提示

- 面板文案"前情自动取最近 3 章"是兜底值；摘要链可用时实际注入"最近 2 章原文 + 摘要链"。
- 多轮会话为**内存态**：重启即失、按"书 + 章"隔离、切章自动清账。
- 多候选与会话微调互斥（会话模式下固定单候选）；多候选仅续写 / 改写可用。
- "继续补完"在改写 / 对白中断后也可用，但实际按续写逻辑接写。
- 用量统计覆盖对话类调用，不含向量嵌入与图片生成。
