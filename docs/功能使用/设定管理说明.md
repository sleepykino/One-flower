# 设定管理使用介绍

> 设定是 AI 写作质量的根基：角色卡、世界书、伏笔、时间线等在写作前建设好，AI 生成时会自动检索注入。新手引导的建议顺序：**先建角色卡与世界书条目，再开始 AI 续写**。

---

## 一、入口结构

| 位置 | 内容 |
|---|---|
| 编辑器右栏「设定」分组 | 上下文 / 角色 / 世界书 / 伏笔 四个 tab |
| 编辑器顶栏「世界构建」下拉 | 地图 / 时间线 / 命名生成（全屏窗口） |
| 角色面板右上「关系图」 | 全屏角色关系图 |

「上下文」面板不属于设定本身，它展示**每次 AI 调用实际注入的完整上下文清单与 token 占用**（角色卡、世界书 RAG、摘要链等分段可见），并提供全书 RAG 索引的「批量向量化」入口。

## 二、角色卡

- **新建 / 编辑**：字段由模板驱动，默认模板为 姓名（必填）/ 外貌 / 性格 / 背景 / 关系；底部可加标签（顿号分隔）。头像 / 立绘在**保存角色后**才能设置（本地上传 / AI 生成 / 图库三源，同一角色至多一张）。
- **模板构建器**：表单右上「编辑模板」——把字段类型（文本 / 多行 / 选择 / 标签 / 数字）拖入字段区，改标题、必填、排序；右侧实时预览表单效果；支持模板 JSON 导入导出（导出的是**字段模板**而非角色数据）。
- **与 AI 的关系**：续写 / 对白时通过 AI 面板「参与角色」勾选注入（按当前章出场频率优先，预算约 1500 token，长文模式放大到 5000）；检查模式自动比对**全部**角色卡；正文 `@角色` 引用则全文强制注入。
- **角色采访**：右栏「灵感 → 角色采访」可让 AI 扮演角色接受提问，摘要确认后写回角色卡，见 [灵感工具说明](./灵感工具说明.md)。

## 三、角色关系图

角色面板「关系图」进入全屏画布（React Flow）：

- 节点默认圆形布局，可拖拽；「重排」一键重排；带缩放控件与小地图。
- **建关系**：点「＋连线」→ 依次点两个角色 → 点边编辑：关系类型（师徒 / 敌对 / 恋人 / 亲属 / 主仆 / 盟友 / 同门 / 其他 八种固定预设）、描述、是否双向（取消勾选后带箭头与流动动画）。
- **单击节点**直接打开该角色编辑表单。

## 四、世界书（RAG）

每条目只有三个字段：**标题、分类（地点 / 势力 / 物品 / 事件 / 其他）、内容**，外加「启用」开关——不是"关键词触发"式世界书，启用的条目会参与**向量检索**自动注入。

- **向量化**：保存条目后自动向量化（需在「模型分工 → 向量嵌入」配置 embedding 模型）；也可用工具条「批量向量化」手动补齐（跳过未变更条目）。**导入的条目不会自动向量化**，导入后请手动批量执行一次。
- **检索注入**：续写时以"当前章末尾约 2000 字"为查询，三路并行召回（摘要链 top5 + 世界书条目 top3 + 原文片段 top3），按相似度排序取 top-K，无阈值过滤；对白模式以场景描述为查询；检查模式则**全量注入**启用条目。
- **章节片段 RAG**：章节保存后 8 秒自动向量化新增段落（200–500 字/段）；存量旧书可在「上下文」面板「批量向量化全书」补齐索引。
- **引用联动**：正文 `[[条目]]` 引用全文强制注入；删除条目时会自动同步移除全部章节中的引用节点并提示数量。
- 条目支持 JSON 导出 / 导入（含启用状态）。

## 五、命名生成器

顶栏「世界构建 → 命名生成」：

- 选项：类型（角色 / 地点 / 招式 / 势力）× 题材（武侠 / 仙侠 / 玄幻 / 科幻 / 奇幻 / 都市 / 历史 / 西幻）× 性别（仅角色）× 数量（1–20，默认 10）+ 其他要求（如"姓林，单字"）。
- 结果为名字 + 含义卡片，可「☆收藏」；角色类可一键「创建角色卡」（含义写入背景字段），地点 / 招式 / 势力可「存入世界书」（招式归类为"功法"）。
- 收藏夹视图跨生成保留，按书隔离。

## 六、伏笔追踪

右栏「设定 → 伏笔」，「列表 / 时间线」双视图：

- **列表**：填描述（如"主角背上的胎记"）+ 埋设章节 + 回收章节（可空）添加；状态徽标 已埋设（琥珀）/ 已回收（绿）/ 已放弃（灰）；可随时切换状态或重新打开。
- **时间线**：章节横轴 × 伏笔行，埋设绿点起、回收蓝点止；**未回收的琥珀色条会延伸到最新章节并脉冲提示**；支持"全部 / 未回收 / 已回收 / 已放弃"过滤，点击区间条跳到埋设章节。
- 章节树上的绿点 / 蓝点只是展示标记，**标记操作在伏笔面板完成**。

## 七、故事时间线

顶栏「世界构建 → 时间线」：多泳道事件视图，纯手动管理。

- 「＋新线」创建泳道（如主线 / 支线）；顶部标签页按泳道筛选。
- 卡片：标题 / 描述 / 关联章节 / 关联角色（多选）；**同泳道拖拽排序，跨泳道拖拽移动**（落到目标线末尾）。
- 无日期字段，顺序完全由拖拽决定，适合梳理多线剧情。

## 八、设定事实（时代感基线）

世界书面板第二个 tab。两步流程 + 一次自动检测：

1. **「抽取事实」**：从世界书条目 / 角色卡 / 章节正文中抽取可核验事实（物件 / 技术 / 社会 / 魔法 / 地理等），带置信度与依据摘录；任务中心托管可取消，自动去重。
2. **「推导前提链」**：按领域推导"前提 → 结论"链（如：无光学工艺 → 不应出现望远镜）。重新推导会替换现有链。
3. **越级矛盾检测**：非豁免事实与推导链作为"时代感基线"**自动注入 AI 面板「检查」模式**，无需单独操作；检测结果并入一致性报告。

个别架空设定可勾选「架空豁免」（不计入基线并级联豁免其推导链）。

## 九、模型分工

| 功能点 | 建议强度 |
|---|---|
| 一致性检查 / 设定事实抽取 / 推导链 | 中档模型 |
| 命名生成 | 中档模型 |
| 向量嵌入 / 章节摘要 | 省钱优先（后台自动任务） |

完整配置方法见 [模型接入说明](./模型接入说明.md)。

## 十、限制与提示

- 向量化、检索都依赖已配置 embedding；未配置时世界书"自动向量化"会静默跳过，条目上的绿点表示已向量化。
- 关系类型为八种固定预设，不能自定义新增。
- 推演报告、采访摘要等灵感数据随书备份；全局种子与收藏的灵感卡片不在单书备份范围内。
