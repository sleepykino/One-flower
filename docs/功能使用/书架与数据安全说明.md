# 书架与数据安全使用介绍

> 本地优先应用的"防误删 + 防丢失"双保险：书架负责组织与入口（新建 / 导入 / 排序 / 备份），回收站负责防误删（软删除可恢复），手动与自动备份负责防丢失（标准 zip 随时可迁移）。

---

## 一、书架管理

书架首页（应用启动页）：

- **新建书籍**：右上紫色按钮，书名必填，类型 / 作者选填。
- **搜索与筛选**：搜索框匹配书名 / 类型 / 作者；类型下拉按现有书籍去重；排序四种——最近更新（默认）/ 创建时间 / 书名 / **手动排序**（该模式下可拖拽书卡，置顶书恒排最前且不可拖）。
- **置顶**：⋮ 菜单「置顶」，恒排最前并显示图钉。
- **书卡**：封面（无封面时显示书名前两字渐变占位，hover 可设置）、书名、类型 · 作者、章节数 · 总字数 · 更新时间。
- **⋮ 菜单**：编辑信息 / 置顶 / 导出备份 / 删除。

## 二、导入

书架右上「导入」下拉两项：

- **导入文档**：TXT / Markdown，按章节标题自动切分卷 / 章。识别「第X卷 / 第X部」「第X章 / 第X节 / 第X回 / Chapter N」及序章、序幕、楔子、引子、尾声、终章、番外等固定章名；Markdown 标题行同样匹配；无法识别边界时导入为单章"全文"。
- **拖入书架**：直接把 `.txt / .md` 文件拖到书架区域即可按同规则导入（支持多文件）；其他格式会提示仅支持 TXT / Markdown。
- **导入备份**：选择 `.zip` 备份包，先自动校验完整性（meta / 章节文档）再恢复。

## 三、回收站（防误删）

主页侧栏「回收站」：

- **删除书籍 = 软删除**：正文 / 设定 / 图片原地保留，恢复零损耗；确认文案会说明可随时恢复。
- **保留期**：7 天 / 30 天（默认）/ 90 天 / 永久保留；超过保留期在**下次启动时自动清理**。
- **恢复**：一键回到书架。
- **彻底删除**：不可恢复；确认时可勾选「同时删除其自动备份文件（N 个 zip）」（默认不勾，只清理自动备份目录，手动导出到别处的备份不受影响）；「清空回收站」走同一确认流程。
- 已删除的书即使通过链接直接打开也会被拦截，提示先恢复。

## 四、手动备份与恢复

- **导出备份**：书卡 ⋮「导出备份」或设置页「备份与恢复」，产出标准 `.zip`（与自动备份格式完全一致）。
- **备份包内容**：书籍元数据与章节树、逐章正文、角色卡与模板、世界书与设定事实、伏笔、图片资产、agents.md / hook.md / outline.md 指令、地图数据与底图、剧本与分镜图、写作统计与目标、长文会话等。
- **导入恢复 = 恢复为一本新书**，不覆盖现有书籍；所有 ID 重新生成并重映射正文内引用，同名书可重复导入。
- **备忘录备份**：全局备忘录单独成包，在设置页「备份与恢复」导入（按新 ID 重建为副本）。

## 五、自动定期备份

设置页「数据 → 备份与恢复」：

| 项 | 说明 |
|---|---|
| 启用开关 | 默认间隔**每 24 小时**，可选 6 / 12 / 24 小时、3 天、7 天 |
| 备份目录 | 默认 `{应用数据目录}/backups`，可更改与打开 |
| 保留份数 | 每书保留最近 N 份（1–99，默认 5），自动轮换清理旧份 |
| 执行方式 | 后台静默运行，任务中心显示"自动备份 · N 本书 + 备忘录"进度，可取消 |
| 范围 | 全部未删除书籍逐书成包 + 备忘录单独成包；**已删除书籍不参与** |

另有「立即备份」「清除无效备份」（清理书籍已删除 / 改名后遗留的孤儿 zip）。

## 六、数据存储与安全

- **全部本地存储**：SQLite 数据库 + 书籍文件目录（正文 JSON / 图片 assets / 指令文件），无云端依赖；断网也能写作。
- **密钥安全**：API Key 存于操作系统钥匙串（Windows 凭据管理器 / macOS Keychain），不落数据库与明文文件。
- **应用数据目录**：设置页「数据 → 数据管理」可查看并一键打开。
- **新手引导**：首次启动自动播放"快速上手"主线引导（创建书籍 → 书架 → 配置 AI → 打开书）；设置页「使用引导」可随时重看全部引导，包括各面板的「?」单点引导。

## 七、限制与提示

- 备份不包含：Skill 目录（应用级，需自行拷贝 `~/.novelagent/skills`）、全局收藏的灵感卡片与故事种子、地图全局素材库。
- 搜索 / 筛选为本地内存计算，书籍极多时建议善用类型筛选。
- 换机迁移 = 旧机导出备份 zip（或整目录自动备份）→ 新机书架「导入备份」。
