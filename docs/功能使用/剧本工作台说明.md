# 剧本工作台使用介绍

> 小说 → 剧本 → 分镜的转化链路，为短剧 / 漫画等衍生形态铺路：选章节范围让 AI 生成"集 / 场"大纲，逐场生成镜头列表与对白，再为每个镜头配分镜图，最后导出 Fountain 专业剧本或 Markdown 分镜表。

---

## 一、进入方式

编辑器右栏「工具 → 剧本」：

- 面板内「从章节转化」直接进向导；「+ 新建」建空白剧本；卡片显示状态（草稿 / 大纲中 / 生成中 / 待确认 / 已完成）与"N 集 · N/N 场"进度。
- 点「打开剧本工作台」进入全屏窗口——剧本编辑、分镜画板与转化向导都在这里完成；顶栏可切换剧本、查看统计（N 集 · N/N 场 · N/N 镜有图）与导出。

## 二、转化向导（四步）

1. **选择章节范围与集数**：起始 / 结束章节下拉；集数滑杆 1–12（默认 1）；每集场次数 3–10（默认 6）；补充提示（可选，如"快节奏改编，合并支线，保留主线冲突"）→ 点「生成大纲」。大纲依据章节摘要、角色卡、世界书与 agents.md 生成。
2. **检查并编辑大纲**：逐集改标题与一句话梗概；逐场改 INT/EXT、地点、时间、概要，可「✕」删场、「+ 加一场」。**编辑只影响未生成的场**。
3. **成本确认**：底部预估条显示"预估 X 次模型调用 · 约 Y tokens（逐场生成，任务中心可暂停 / 恢复，已完成场不重做）"。
4. **开始生成**：点「确认并开始逐场生成」，工作台自动切到剧本编辑视图。

## 三、逐场生成（任务托管）

- 每场产出：**镜头列表**（景别 远/全/中/中近/近/特写、运镜、画面描述、时长）与**对白**（角色、语气、台词），每场 3–8 个镜头。
- 由**任务中心托管**：底部状态栏显示进度徽标与"第 N 集 · 第 M 场"详情；中途停止（任务中心「取消」）后当前场写完即停，**已完成场不重做**；在右栏属性区点「生成剩余 N 场」即可恢复。
- 生成素材：来源章节节选、出场角色卡、按场景关键词检索的世界书条目；**agents.md 的称谓与禁令、作者全局要求与文风 Skill 对剧本对白同样生效**。
- 剧本状态流转：草稿 → 待确认（大纲确认后）→ 生成中 → 已完成。

## 四、剧本编辑器（三栏）

- **左栏场次树**：按集分组，场行显示序号、状态圆点（绿 = 已生成）、INT·地点、镜头数；可按集加场。
- **中栏结构化表单**：场景头（INT/EXT、地点、时间、概要）+ 镜头卡（景别 / 运镜 / 时长 / 画面描述 / 对白行），「+ 加镜头」「+ 对白」自由增删；改动 500ms 防抖即时保存；删除镜头 / 对白 / 场后底部出现 8 秒撤销条。
- **右栏属性**：本场统计、上移 / 下移 / 删除；「溯源章节 → 打开来源章节 ↗」一键跳回编辑器对应章节核对正文；「转化进度」区可恢复剩余场的生成。

## 五、分镜画板

工作台顶栏切到「分镜画板」：镜头卡片网格（含景别 / 运镜 / 时长 / 描述 / 对白 / 场景头），顶部按集筛选与"共 N 镜 · 缺图 M"统计。

每个镜头图片三种来源：

1. **AI 生成分镜图（2 候选）**：自动拼接镜头描述、运镜 / 景别英文词与**出场角色的外貌设定**（从角色卡取外貌 / 服饰 / 发型等字段，保持人物一致性），1536×1024 双候选单选入库。
2. **上传图片**（png / jpg / webp / gif / bmp）。
3. **从图库选**（本书全部图片）。

已有图可「重新生成 / 上传 / 图库 / 清除」。「AI 批量补图（M）」逐镜执行全部缺图镜头，任务中心托管、可取消、单镜失败跳过并计数。

## 六、导出

工作台顶栏两个按钮：

- **导出剧本**：Fountain 格式（`.fountain`），含标题页、集标题、场景头、镜头注记与对白，Slugline / Fade In 等专业剧本工具可直接识别。
- **导出分镜表**：Markdown 表格（场 / 镜 / 景别 / 运镜 / 描述 / 时长 / 对白 / 分镜图），分镜图输出到同级 `storyboard/` 目录相对引用。

## 七、模型分工

| 功能点 | 建议强度 |
|---|---|
| 剧本大纲 | 中档模型（规划任务） |
| 剧本逐场生成 | 强模型（写作生成） |
| 分镜图 | 复用「图片生成」功能点（生图模型） |

## 八、限制与提示

- 删除剧本时分镜图**保留在图库**，不会级联删除。
- 随书备份包含剧本全部结构与分镜图；导入恢复时章节溯源与图片引用自动重映射。
- 对白角色名要求与素材中角色名一致，建议先完善角色卡的姓名字段。
