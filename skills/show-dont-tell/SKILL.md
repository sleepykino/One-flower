# 展示而非告知

## 改写公式
- 情绪 → 行为：他愤怒 → 他把烟摁灭在还剩大半的烟上
- 情绪 → 生理：她紧张 → 她把台词在心里过了第三遍，还是忘了第一句
- 情绪 → 对话：他嘴硬 → "随便你。"他说完把门带得很轻
- 性格 → 习惯动作与选择：他抠门 → 打车前先看三种优惠券，最后选了公交
- 关系 → 距离与物件：两人生疏 → 递东西的时候，指尖没碰到一起

## 执行
- 通读文本，圈出所有情绪词、性格标签词、评价词（愤怒、温柔、尴尬、抠门、关系很好）
- 每个词换成上面四种公式之一；一处告知只换一处展示，不重复展示
- 环境也参与展示：心事重重的人眼里，雨停了地面还是湿的

## 边界
- 展示要控制密度：关键情绪给展示，过场情绪可以直陈，全篇都"演"会拖节奏
- 事实性信息（时间、地点、身份）直接告知，别绕着演
- 保留原文信息量，只换呈现方式

## 示例（仿写）
> 改前：听到父亲去世的消息，她非常悲伤，一时无法接受。
> 改后：电话是她妈打来的。她说知道了，然后问，晚饭的排骨还在锅里炖着吗。
