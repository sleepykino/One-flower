# 一花一世界

基于 Vue 3 + TypeScript 开发的智能续写工具，支持调用多个大模型 API 进行 AI 辅助创作。集角色卡、世界书、地图编辑于一体，让 AI 续写更加智能和个性化。

## 功能特点

### 核心功能

- **智能续写**: 支持多个大模型 API（GLM、DeepSeek、OpenAI、Claude、Grok 等），可根据上下文和提示词智能续写小说内容
- **自定义 API**: 支持添加自定义 API，适配任何兼容 OpenAI 格式的 API 服务
- **角色卡系统**: 类似 SillyTavern 的角色卡功能，可以创建和管理角色信息，包括性格、外貌、背景、说话风格等
- **世界书功能**: 支持创建世界设定条目，通过关键词触发，自动注入相关设定信息
- **地图编辑**: 内置像素瓦片地图编辑器，支持地形笔刷自由绘制、随机地形生成（Perlin 噪声 + 多种预设）与 AI 生成地图
- **章节管理**: 树形结构章节管理，支持添加、删除、移动、展开/折叠章节
- **文风选择**: 内置多种写作风格（默认、快节奏爽文、言情细腻、悬疑智斗、诗意文学），支持自定义提示词
- **富文本编辑**: 基于 Quill 的富文本编辑器，支持标题、加粗、斜体、下划线、删除线、颜色、背景色、列表、缩进、链接、图片等格式
- **导出功能**: 支持将所有章节导出为 TXT、Markdown、EPUB 格式
- **导入功能**: 支持导入 TXT 和 Markdown 格式的小说文件

### 角色卡功能

- **多角色管理**: 创建和管理多个角色，每个角色都有独立的属性
- **详细角色信息**: 支持设置角色名称、描述、性格、外貌、背景故事、说话风格、人物关系、备注等
- **标签系统**: 为角色添加标签，方便分类和查找
- **启用/禁用**: 可以灵活控制哪些角色参与续写
- **导入导出**: 支持角色数据的导入导出（JSON 格式）
- **快速复制**: 一键复制角色卡，方便创建相似角色
- **关系图谱**: 可视化展示角色之间的关系，支持添加、编辑关系类型

### 世界书功能

- **多世界书管理**: 创建多个世界书，每个世界书可以包含不同的设定
- **分组管理**: 将世界书条目分组管理，便于组织不同类型的设定
- **关键词触发**: 通过关键词自动触发相关设定，支持正则表达式
- **优先级控制**: 设置条目优先级，控制注入顺序
- **灵活配置**: 支持设置扫描深度、令牌预算、递归扫描等参数
- **位置控制**: 控制条目注入的位置（角色前/后、示例前/后）
- **导入导出**: 支持世界书的导入导出（JSON 格式）

### 地图编辑功能

- **瓦片地图系统**: 以像素瓦片地图为主体，三层 Canvas 分离渲染（地形层 / 网格层 / 标注层），画笔操作只重绘地形层，大地图也流畅
- **多地图管理**: 创建、复制、删除多个地图，支持搜索筛选
- **四套瓦片集**: 奇幻世界、像素地形、孤岛海域、跑团地牢，每种含完整地形调色板与图章素材
- **地形随机生成**: 基于 Perlin 噪声 + 域扭曲 + 众数平滑后处理，内置 7 种地形预设（广袤大陆、群岛海域、孤岛、崇山峻岭、平原沃野、荒漠戈壁、地牢），支持种子、海平面调节
- **自由绘制工具**: 画笔（方形/圆形笔刷、1-12 格大小）、橡皮擦、油漆桶填充、直线、矩形、取色器、图章、文字标注
- **AI 生成地图**: 通过 AI 按自然语言描述生成整张瓦片地图（ASCII 字符网格方案），可同时生成地点图章与地名标注，支持所有已启用的 AI 提供商
- **视图控制**: 10 级缩放（像素完美渲染）、适应窗口、网格显示、等高线、图层开关
- **视图操作**: 原生滚动视口平移，支持空格临时平移、中键拖动、右键擦除
- **导出功能**: 支持导出为 PNG/JPG 图片（1x/2x/4x 质量）或 JSON 数据，瓦片导出保持像素清晰
- **撤销重做**: 一次笔刷操作 = 一步历史记录
- **快捷键**: 工具切换（B/E/F/L/R/I/S/H/G）和操作快捷键（Ctrl+Z/Y/S）

### 界面设计

- **标签页导航**: 编辑器、角色卡、世界书、地图、设置五大模块标签页切换
- **响应式布局**: 适配不同屏幕尺寸
- **实时字数统计**: 显示当前章节字数
- **直观的操作界面**: Element Plus UI 组件，简洁美观
- **智能提示**: 续写时显示启用的角色数量和匹配的世界书条目
- **亮色主题地图编辑器**: 地图编辑器采用亮色主题三栏布局 + 底部状态栏，简洁清爽

## 技术栈

- **框架**: Vue 3 (Composition API)
- **语言**: TypeScript
- **UI 框架**: Element Plus
- **富文本编辑器**: Quill
- **状态管理**: Pinia
- **数据库**: IndexedDB (Dexie.js)
- **HTTP 客户端**: Axios
- **压缩库**: JSZip
- **路由**: Vue Router
- **构建工具**: Vite
- **代码规范**: ESLint + Prettier

## 使用指南

### 1. 配置 AI 模型

- 点击顶部导航栏的"设置"标签
- 在 AI 模型配置区域，您可以看到所有支持的 AI 提供商
- **配置内置提供商**：
  - 找到想要使用的提供商（如智谱 AI、DeepSeek、OpenAI 等）
  - 输入 API Key
  - 开启提供商开关
  - 选择要使用的模型
- **添加自定义 API**：
  - 点击"添加自定义 API"按钮
  - 填写 API 名称、地址、模型 ID 等信息
  - 如需高级配置，可以设置自定义请求头和请求体模板
- **切换模型**：
  - 在已启用的提供商中选择模型
  - 选中的模型将用于续写功能

### 2. 创建角色卡

- 点击"角色卡"展开角色管理面板
- 点击"添加角色"创建新角色
- 填写角色信息：
  - **基本信息**: 名称、描述、头像 URL、标签
  - **性格特征**: 性格、说话风格
  - **背景故事**: 外貌描述、背景故事
  - **关系备注**: 人物关系、其他备注
- 使用开关控制角色是否参与续写
- 可以复制、删除、导入导出角色

### 2.1 角色关系图谱

- 在角色卡管理页面，点击"关系图谱"按钮切换到图谱视图
- 图谱会自动显示所有角色及其关系
- **添加关系**：
  - 点击"添加关系"按钮
  - 选择两个角色
  - 选择关系类型（朋友、敌人、家人、恋人、同事、对手、师徒、学生、其他）
  - 填写关系描述
- **图谱交互**：
  - 拖拽节点可以调整位置
  - 滚轮缩放图谱
  - 拖拽空白区域平移视图
  - 点击节点查看角色详情
  - 点击"重置视图"恢复初始状态
- 关系图谱帮助可视化角色之间的复杂关系网络

### 3. 创建世界书

- 点击"世界书"展开世界书管理面板
- 点击"新建世界书"创建世界书
- 在世界书中创建分组（如：地理设定、历史背景、魔法体系等）
- 在分组中添加条目：
  - **键名**: 条目的唯一标识
  - **关键词**: 触发该条目的关键词（支持多个）
  - **内容**: 条目的详细内容
  - **优先级**: 控制注入顺序（数值越大越优先）
  - **位置**: 控制注入位置
  - **高级选项**: 区分大小写、使用正则表达式
- 当续写内容包含关键词时，相关条目会自动注入到 AI 提示词中

### 4. 地图编辑

- 点击顶部导航栏的"地图"标签进入地图模块
- **创建地图**：
  - 点击左侧"新建"按钮创建地图
  - 新地图自动初始化为 80 × 80 瓦片画布，可随时在顶栏调整尺寸
- **随机生成地形**：
  - 点击顶栏"✨ 随机生成"按钮（快捷键 G）
  - 选择地形预设卡片（广袤大陆 / 群岛海域 / 孤岛 / 崇山峻岭 / 平原沃野 / 荒漠戈壁 / 地牢）
  - 可选填种子（相同种子生成相同地图）或点击 🎲 随机
  - 调节海平面（地牢预设则调节房间数），点击"生成"
- **AI 生成地图**：
  - 点击顶栏"🤖 AI 生成"按钮
  - 选择瓦片集、尺寸（32/48/64）、AI 模型
  - 用自然语言描述想要的地图（如"中央火山岛，北部森林，两个港口城镇"）
  - AI 将生成整张瓦片地图，并附带地点图章与地名标注
- **自由绘制**：
  - 左侧工具栏切换工具：画笔(B)、橡皮(E)、填充(F)、直线(L)、矩形(R)、取色(I)、图章(S)、平移(H/空格)
  - 可调笔刷大小（1-12）与形状（方形/圆形）
  - 右键快速擦除；中键或空格+拖动平移视图
  - 右侧面板选择地形瓦片、emoji 图章，输入文字后点击画布放置标注
- **视图控制**：
  - 左侧"视图"区：网格、等高线、地形/网格/标注图层开关
  - 缩放按钮 + / － / 适应窗口，10 级像素完美缩放
- **导出地图**：
  - 点击"导出"按钮
  - 选择格式（PNG/JPG/JSON）、图片质量
  - 瓦片导出关闭平滑，保持像素清晰

### 5. 章节管理

- 点击"章节管理"展开章节列表
- 点击"添加章节"按钮创建新章节
- 右键点击章节可进行删除、移动等操作
- 点击章节标题切换到对应章节

### 6. 文风选择

- 在设置页面的"写作风格"中选择预设的写作风格
- 或在提示词框中输入自定义提示词来控制 AI 续写风格

### 7. 编写小说

- 在编辑器中输入您的小说内容
- 使用工具栏进行格式设置（标题、加粗、斜体、颜色等）
- 实时查看字数统计

### 8. 续写小说

- 点击"续写"按钮
- 在弹出的对话框中：
  - 输入续写提示词
  - 选择模型和续写长度
  - 查看启用的角色数量
  - 查看匹配的世界书条目
  - 选择是否使用角色卡和世界书
- 点击"开始续写"等待 AI 生成内容
- 续写内容会自动插入到编辑器末尾

### 9. 保存和导出

- 点击顶部"保存"按钮将当前内容保存到 IndexedDB
- 在编辑器中点击"导出"按钮可选择导出格式：
  - **TXT 格式**: 纯文本格式，适合备份和分享
  - **Markdown 格式**: 保留格式信息的 Markdown 文件，适合二次编辑
  - **EPUB 格式**: 电子书格式，适合在各种电子书阅读器中阅读

### 10. 导入小说

- 点击"导入"按钮可选择导入格式：
  - **TXT 文件**: 支持导入纯文本格式的小说，会自动识别章节
  - **Markdown 文件**: 支持导入 Markdown 格式的小说，会保留格式信息
- 导入时会自动识别章节标题和内容
- 导入前会显示识别到的章节数量，确认后替换当前内容

## 配置说明

### API 密钥配置

- GLM API 密钥: 在智谱 AI 开放平台获取
- DeepSeek API 密钥: 在 DeepSeek 开放平台获取

### 温度参数

- 范围: 0-2
- 低值（0-0.3）: 输出更确定、保守
- 中值（0.3-0.7）: 平衡创造性和一致性
- 高值（0.7-2）: 输出更有创造性、多样性

### 写作风格

- 默认: 和原文保持一致
- 快节奏爽文: 情节紧凑，爽点密集，语言简练有力
- 言情细腻: 注重情感描写，语言优美，情感丰富
- 悬疑智斗: 设置悬念，逻辑严密，注重推理过程
- 诗意文学: 语言优美，意境深远，富有文学性

### 世界书配置

- **扫描深度**: 控制扫描文本的深度（默认 2）
- **令牌预算**: 世界书条目的最大令牌数（默认 2048）
- **递归扫描**: 是否递归扫描匹配的条目

## 角色卡与世界书的工作原理

### 角色卡注入

当启用角色卡时，AI 会在续写时收到以下格式的角色信息：

```
=== 角色信息 ===
【角色：张三】
描述：主角，年轻剑客
性格：勇敢、正直、有些冲动
外貌：身材高大，剑眉星目
背景：出身武林世家，自幼习武
说话风格：直爽豪迈，不拘小节
人物关系：与李四是好友
备注：擅长剑法，特别是"流云剑法"
=== 角色信息结束 ===
```

### 世界书触发

当文本中出现关键词时，相关的世界书条目会被注入：

```
=== 世界设定 ===
【流云剑法】
张家的家传剑法，以快速灵活著称，共有三十六式，其中最厉害的是"云龙九现"。

【武林盟】
江湖上最大的组织，由各大门派组成，负责维护江湖秩序。
=== 世界设定结束 ===
```

## 数据存储

所有数据存储在浏览器的 IndexedDB 中（使用 Dexie.js），包括：

- 章节内容和结构
- 角色卡数据与角色关系
- 世界书数据（世界书、分组、条目）
- 合集数据
- AI 提供商配置
- 地图数据
- 应用设置（文风偏好、选中的模型等）

> 旧版本使用 localStorage 存储，首次启动时会自动迁移到 IndexedDB。
